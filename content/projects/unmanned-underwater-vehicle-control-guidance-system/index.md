This project delivered the full firmware stack for an unmanned underwater vehicle control unit on STM32, including propulsion and guidance control loops. It also implemented a passive target detection and guidance algorithm for single-hydrophone sensing, enabling edge-side autonomous operation in constrained embedded conditions.
